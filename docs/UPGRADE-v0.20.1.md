# Upgrade to v0.20.1

v0.20.1 fixes TrueNAS System host-update execution from v0.20.0.

No Docker Compose, Dockge Compose, environment-variable, connection, or manual database changes are required. Preserve `/app/data` and update the Dashboard image normally.

After upgrading, run **Check for updates** again and verify the TrueNAS card still reports the expected current and available versions before using **Update & reboot**.
