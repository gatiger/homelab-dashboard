# Homelab Dashboard v0.13.0

v0.13 turns the growing collection of configuration controls into a central Settings experience and adds the first persistent dashboard widgets.

## Highlights

- New Settings hub: General, Appearance, Connections, Monitoring, Extensions, and About.
- Persistent dashboard title and greeting preference.
- Configurable live telemetry, cached update-state, active-job, and scheduled update-discovery intervals.
- Clock & Date, Note, Bookmarks, and Dashboard Summary widgets.
- Widgets support dashboard pages, categories, enabled/hidden state, and Compact/Standard/Wide sizing.
- Extension Manager inventory for built-in modules and imported data-only themes.
- Widget-aware category counts/order and page-deletion safeguards.
- No new Docker privileges and no Compose change required from v0.12.

## Extension safety

v0.13 does not enable arbitrary executable community plugins. Imported themes remain validated data-only packages. The open extension runtime, capability/permission model, SDK, and registry remain future milestones.

See `docs/UPGRADE-v0.13.md` before upgrading.
