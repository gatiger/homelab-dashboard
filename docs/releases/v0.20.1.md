# Homelab Dashboard v0.20.1

v0.20.1 is a hotfix for the TrueNAS System **Update & reboot** path introduced in v0.20.0.

## Fixed

- TrueNAS long-running job methods are now started through the documented `core.get_jobs` event flow. Dashboard subscribes to the job collection, correlates the update job to the JSON-RPC call ID, captures the TrueNAS middleware job ID, and then polls that job for progress.
- The previous v0.20.0 implementation incorrectly treated `update.run` like a short ordinary RPC call, which could time out before the long-running update job returned its normal method result.
- Failed update jobs now expose their backend detail text in Update History.

## Upgrade

No Compose, environment-variable, or database changes are required. Preserve `/app/data` and update normally. Existing v0.20.0 settings and TrueNAS connections are retained.
