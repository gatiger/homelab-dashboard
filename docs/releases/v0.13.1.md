# Homelab Dashboard v0.13.1

v0.13.1 is a build-system hotfix for v0.13.0.

## Fixed

- The frontend build stage now runs on the native GitHub Actions build platform instead of running Node/npm under ARM64 QEMU emulation.
- Multi-architecture container publishing no longer needs to perform a second emulated frontend dependency installation/build for ARM64.
- Application functionality and the v0.13 database schema are unchanged from v0.13.0.

## Upgrade notes

This release has no database or Compose migration beyond v0.13.0. Existing dashboard data, settings, services, widgets, connections, and update-agent configuration are preserved.
