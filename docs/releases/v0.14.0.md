# Homelab Dashboard v0.14.0

v0.14 is the Advanced Dashboard Builder release. It reduces header clutter, makes service and widget layout behavior consistent, and adds portable dashboard structure tools without weakening the project's credential boundaries.

## Highlights

- Compact responsive command bar with Updates, Manage, Add, and Menu controls.
- Amber attention badge for available updates without a permanent oversized Updates button.
- Unified drag ordering for unpinned service cards and widgets in the same category.
- Deterministic desktop/tablet/mobile card widths.
- Category rename and icon customization.
- Page cloning.
- Safe dashboard layout export/import from Settings → Dashboard.
- Visual custom-theme editor built on the existing data-only theme format.
- New Service Status and Update Overview widgets.

## Security and portability

Layout exports contain no passwords, API keys, encrypted secrets, controller credentials, or active management links. They are intended for sharing/reusing dashboard structure and are not a replacement for backing up `/app/data`.

Custom themes remain validated design-token data. v0.14 does not enable arbitrary CSS, JavaScript, Python, shell commands, or third-party executable extension code.

## Upgrade

No Compose changes are required from v0.13.1. See `docs/UPGRADE-v0.14.md`.
