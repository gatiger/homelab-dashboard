# Homelab Dashboard v0.11.0

v0.11 turns Homelab Dashboard into an optional service update control plane while keeping platform-specific lifecycle operations behind explicit management providers.

## Highlights

- One-click service updates from the dashboard
- Update availability badges and persistent history
- Background progress and sequential Update All
- Docker Compose/Dockge update provider through a restricted sidecar
- Docker health verification and automatic previous-image rollback
- TrueNAS App discovery/upgrades through the JSON-RPC WebSocket API
- Automatic update discovery (12-hour default) plus manual checks
- Application integrations and management providers are now separate concepts

## Security / deployment note

Docker updates are **opt-in**. The main dashboard still does not mount the Docker socket. Users who want Docker/Compose updates enable `compose.management.yaml`; only the update-agent receives the socket, its API stays on an internal network, stack definitions are mounted read-only, and it only operates on discovered Compose services under an explicit stacks-root allow list.

TrueNAS Apps are upgraded by TrueNAS itself through its authenticated API rather than by touching underlying containers.

See `docs/UPGRADE-v0.11.md` and `docs/configuration/update-manager.md`.
