# Homelab Dashboard v0.12.0

v0.12 makes managed service cards feel live and removes the requirement to create controller cards solely for platform credentials.

## Highlights

- Reusable **Connections** model, starting with TrueNAS.
- Automatic v0.11 TrueNAS controller-card migration.
- Consistent card layout regions for connectivity, app activity/details, and update management.
- Glowing green **Up to date**, amber **Update available**, red failure, and blue checking states.
- One-click Update action in the same position on managed cards.
- Automatic browser refresh without manually reloading the dashboard.
- Faster polling while an update is actively running.
- Connection testing and safe deletion protection for in-use connections.

## Upgrade

No manual database migration is required. See `docs/UPGRADE-v0.12.md`. Existing Docker update-agent deployments continue to work unchanged.
