# Homelab Dashboard v0.18.0

v0.18 adds multi-user local authentication and role-based permissions, establishing the authorization layer needed before executable community extensions or external identity providers are introduced.

## Highlights

- Owner, Admin, Editor, and Viewer roles.
- Settings → Users for Owner-managed local accounts.
- Server-side permission enforcement across dashboard editing, secrets, updates, Connections, Extensions, Settings, and user administration.
- Existing single-administrator installations migrate automatically to the first Owner account and preserve valid sessions.
- Per-user recovery codes and security history.
- Disabled accounts and Owner-initiated password resets immediately invalidate active sessions.
- Editors can manage normal dashboard/service content without gaining access to saved credentials or management-provider configuration.
- Viewers get a read-only dashboard while retaining visibility into health/activity/update status.
- Host-side user listing and targeted emergency password reset.

## Upgrade notes

No Compose changes are required. Preserve `/app/data` as usual. See `docs/UPGRADE-v0.18.md`.

## Extension security

Executable third-party extensions remain disabled in v0.18. The new RBAC layer is a prerequisite for the future permission-aware plugin runtime; it is not itself a sandbox for arbitrary extension code.
