# Homelab Dashboard v0.10.0

v0.10.0 completes the original Milestone 4 service-aware integration set and introduces a reusable activity/progress contract for future adapters.

## Highlights

- Shared service capability descriptors and normalized activity/progress records.
- Progress bars show the current item/job name, percentage, transferred/total size, speed, ETA, and additional-activity count when the source API provides those values.
- Sonarr and Radarr: API-backed health, queue progress, and upcoming activity.
- Prowlarr: health and indexer summary.
- qBittorrent: encrypted WebUI credentials, active download progress, speed, and ETA.
- SABnzbd: queue/download progress, speed, and ETA.
- Immich: server version and storage/statistics summary.
- TrueNAS: pool health/capacity plus scrub, resilver, and expansion progress through the REST compatibility API.
- Existing Jellyfin and optional Docker/Dockge insight remain supported through the same insight endpoint.
- Automatic v0.9 database migration preserves existing dashboard data and adds encrypted username/password credential storage.

## Security

Rich integrations are read-only in this release. Stored API keys and qBittorrent credentials remain backend-only and encrypted at rest. No download, storage, or service-control commands were added.
