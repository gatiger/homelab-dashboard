# Homelab Dashboard v0.6.0

v0.6.0 is the first GitHub baseline for Homelab Dashboard.

## Highlights

- Searchable catalog of common self-hosted services.
- Recognizable bundled service logos.
- Persistent administrator account and SQLite configuration.
- Live HTTP service health and response latency.
- Jellyfin session/server integration.
- Read-only local Docker overview for Dockge cards.
- Favorites/pinned services.
- Compact, Standard, and Wide card sizes.
- Persistent drag-and-drop ordering within categories.

## Upgrade notes

Existing v0.5.x and v0.4.x dashboard data is migrated in place by the backend. Keep the `dashboard-data` volume during upgrades.

Do not run:

```bash
docker compose down -v
```

See `docs/UPGRADE-v0.6.md` for the v0.6 upgrade procedure.
