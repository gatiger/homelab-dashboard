# Homelab Dashboard v0.19.0

v0.19 replaces the fixed update-provider list with a platform-neutral, capability-based management-provider framework.

## Highlights

- Runtime management-provider descriptors drive the service editor and Update Manager.
- Docker Compose / Dockge and TrueNAS App behavior now dispatch through the common provider layer.
- TrueNAS System can detect operating-system updates using the native TrueNAS JSON-RPC update API.
- Providers declare whether they support checking, installation, progress, rollback, release notes, reusable connections, and resource/system targets.
- Detection-only updates remain visible but cannot expose an Update action or enter Update All.
- Backend capability checks enforce those boundaries even if a client attempts to call the update endpoint directly.

## Upgrade

No Compose changes are required. Preserve `/app/data` as usual. See `docs/UPGRADE-v0.19.md`.

## TrueNAS system safety boundary

TrueNAS System is detection-only in v0.19.0. The upstream platform can perform system updates, but those updates may reboot the host. Homelab Dashboard will not expose installation until reboot-aware reconnect and operation-recovery behavior is implemented.
