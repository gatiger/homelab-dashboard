# Homelab Dashboard v0.20.2

v0.20.2 is a TrueNAS System host-update compatibility hotfix.

## Fixed

- Dashboard now resolves the TrueNAS update train that provides the exact version detected by `update.status`.
- `update.run` now receives both `train` and `version`, satisfying the TrueNAS 25.10 requirement that those fields are either both null or both non-null.
- The exact detected target version is retained rather than falling back to an unspecified latest release.

## Validation

- Backend regression coverage verifies train resolution and the exact arguments sent to `update.run`.
- Existing persistent host-update/reconnect recovery from v0.20.0 and TrueNAS job tracking from v0.20.1 are unchanged.

## Upgrade

No Compose, environment-variable, connection, or database changes are required. Preserve `/app/data` and update normally.
