# Homelab Dashboard v0.17.0

v0.17 adds registry-based discovery and updates for the safe data-only extension platform.

## Highlights

- Browse extension packages from Settings → Extensions.
- Official / Verified Community / Community trust labels.
- Minimum-dashboard compatibility checks before install.
- SHA-256 verification of the exact downloaded package bytes.
- Same-HTTPS-origin package enforcement for registry downloads.
- Install new registry packages without manually downloading JSON files.
- Detect and install newer versions of already installed data extensions.
- Exact permission/capability matching between registry metadata and package manifests.
- Manual JSON import remains available when the registry is offline.
- Registry validator added to CI and maintainer workflow.

## Security boundary

v0.17 does not enable executable third-party plugins. Registry packages are still limited to the existing page-template and service-catalog registration permissions. A trust label is metadata rather than a cryptographic guarantee; package signing/transparency remain future work before executable extensions are considered.

## Upgrade

No Compose changes are required for normal installations. Preserve `/app/data` as usual and update the dashboard/update-agent images through the normal release process.
