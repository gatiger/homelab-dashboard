# Homelab Dashboard v0.9.0

v0.9.0 introduces the dashboard's appearance system and the first safe extension package format.

## Highlights

- System theme that follows the device light/dark preference.
- Built-in Dark, Light, Slate, Ocean, Forest, Violet, and Amber themes.
- Appearance selection persists in SQLite and follows the account across browsers/devices.
- Importable JSON community theme packages with server-side validation.
- Downloadable theme-authoring template and repository example theme.
- Theme packages are data-only: no CSS, JavaScript, network, Docker, filesystem, or credential access.
- New extension-architecture documentation for future widgets, service packs, integrations, authentication adapters, and printer-provider adapters.
- GitHub container publishing no longer runs automatically on every `main` push; release tags publish stable multi-architecture images while CI continues validating ordinary pushes.

## Upgrade notes

v0.8 data migrates in place. Keep the persistent dashboard data volume during the upgrade. See `docs/UPGRADE-v0.9.md`.
