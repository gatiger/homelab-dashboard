# Homelab Dashboard v0.7.0

v0.7.0 focuses on distribution, installation, and portability.

## Highlights

- New all-in-one production container image.
- Automated multi-architecture GHCR publishing for amd64 and arm64.
- Docker Compose is the reference installation; Dockge is optional.
- Optional Docker host insight is split into a separate Compose overlay.
- Dedicated Docker Host service template; Dockge is no longer the conceptual owner of Docker statistics.
- Installation guides for Docker Compose, Dockge, TrueNAS SCALE, Portainer, Unraid, Synology Container Manager, and QNAP Container Station.
- Backup/restore, updating, and Docker-integration security guides.
- Existing v0.6 database/account/service data remains compatible.

## Upgrade warning

Preserve the existing data volume. Do not use `docker compose down -v` during an upgrade. See `docs/UPGRADE-v0.7.md`.
