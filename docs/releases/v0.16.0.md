# Homelab Dashboard v0.16.0

v0.16 begins the general extension-platform milestone while keeping the security boundary deliberately conservative.

## Highlights

- Versioned `homelab-dashboard-extension` manifest format.
- Explicit capability and permission declarations.
- Safe data-only page-template packs and service-catalog packs.
- Import, enable, disable, and remove community data packs from Settings → Extensions.
- Export an existing page as a reusable template package with secrets and management links excluded.
- Choose built-in or imported templates when adding a new dashboard page.
- Enabled community catalog entries appear automatically in Add Service and the service editor.
- Example extension packages and authoring documentation are included in the repository.

## Security boundary

v0.16 still does **not** execute third-party extension code. Packages cannot gain Docker access, read stored credentials, make arbitrary network requests, access the host filesystem, or inject JavaScript/Python/shell code. Unknown permissions are rejected rather than ignored.

## Upgrade notes

This release adds an `installed_extensions` SQLite table automatically. Existing pages, services, widgets, themes, credentials, update-management settings, and account recovery configuration remain in place.

No Compose changes are required when upgrading from v0.15.x.
