# Homelab Dashboard v0.15.0

v0.15 adds a complete recovery lifecycle for the native local administrator account without requiring SMTP or an external identity provider.

## Highlights

- New **Settings → Account** section.
- Change the administrator password while signed in.
- Other active sessions are invalidated after a password change while the current browser remains signed in.
- High-entropy recovery codes that are displayed only when generated and stored only as digests.
- **Forgot password?** recovery flow on the login screen.
- Recovery codes automatically rotate after successful use.
- Recent account-security activity in Settings without logging credentials.
- Host-side emergency reset command for legitimate Docker/host administrators who lose both the password and recovery code.
- Existing v0.14 administrator accounts migrate in place without losing configuration.

## Existing installations

After upgrading, go to **Settings → Account** and create a recovery code. Existing users do not receive one automatically because the readable secret should only be exposed at the moment the administrator requests it.

## Emergency recovery

From the Docker host:

```bash
docker exec -it dashboard-dashboard-1 python -m app.admin reset-password
```

The command prompts for a new password, invalidates all dashboard sessions, rotates the recovery code, and prints the replacement code once.

## Upgrade

No Compose changes are required from v0.14.x. Preserve `/app/data` as usual.
