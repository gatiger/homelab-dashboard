# Homelab Dashboard v0.8.0

v0.8.0 turns the single dashboard view into a persistent multi-page workspace.

## Highlights

- Multiple dashboard pages/tabs.
- Create, rename, and drag pages into the preferred order.
- Move services between pages from the normal Edit Service screen.
- Persistent category ordering on each page.
- Collapsible categories with collapse state saved in SQLite.
- Existing v0.7 installations automatically migrate to a default Home page without losing cards or integration settings.
- Card reordering is scoped to its page and category.

## Upgrade notes

The database migration is automatic. Preserve the existing dashboard data volume and do not use `docker compose down -v`.

See `docs/UPGRADE-v0.8.md` for the complete procedure.
